# Comprovantes

App de celular (PWA) que lê comprovantes de pagamento em foto, print ou PDF, transcreve favorecido, data, vencimento, conta de destino e valor, e soma o total do mês.

- Os dados ficam só no aparelho (use **Configurações → Fazer backup** de vez em quando).
- Leitura básica no próprio celular, ou leitura inteligente com uma chave gratuita do Google Gemini (Configurações).
- Instalado na tela inicial, aparece na lista de **Compartilhar** do Android: compartilhe o comprovante direto do app do banco.
